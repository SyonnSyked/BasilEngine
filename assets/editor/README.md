# BasilEditor Assets

Repository-owned BasilEditor presentation assets live here so builds do not
depend on fonts or branding installed on a developer's machine.

```text
assets/editor/
|-- fonts/       Bundled typefaces and their licenses
`-- branding/
    |-- source/  Editable master artwork
    `-- icons/   Reviewed platform-ready icon exports
```

Source artwork and exported application icons are kept separate. Generated
build artifacts do not belong in this directory.
