# Platform Icon Exports

Reviewed application icon exports belong here. Planned outputs include a
multi-resolution Windows ICO and lossless PNG sizes suitable for window,
taskbar, Linux desktop, and future macOS packaging use.

All files in this directory are exports of
`../source/basil-editor-icon.svg`. The PNG set is used for inspection and
platform packaging. `basil-editor.ico` contains the 16, 24, 32, 48, 64, 128,
and 256 pixel PNG representations for Windows resources.
