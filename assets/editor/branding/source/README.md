# Branding Source Artwork

Place editable, resolution-independent master artwork here. The preferred
source format is SVG unless the selected design requires another documented
format. Platform exports must be regenerated from this source rather than
edited independently.

`basil-editor-icon.svg` is the selected BasilEditor application mark. Its simple
angular silhouette and limited electric-cyan/violet palette are designed to
survive reduction to taskbar and window-icon sizes.
