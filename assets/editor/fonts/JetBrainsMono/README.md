# JetBrains Mono

BasilEditor bundles JetBrains Mono Regular and Bold from the official
JetBrains Mono v2.304 release.

- Upstream: <https://github.com/JetBrains/JetBrainsMono>
- Pinned release: <https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304>
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory.
- Local use: Regular is the primary editor face. Bold provides hierarchy and
  emphasized interface states without requiring another type family.
